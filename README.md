# Simple AI Chatbot

## About the Project
This is a simple AI chatbot developed using Python.
It interacts with users and gives responses based on
their messages.

## Features
- Greets users
- Answers simple questions
- Responds to Python-related questions
- Exits when the user types bye

## Technology Used
- Python

## How to Run
1. Open the terminal.
2. Type: python chatbot.py
3. Press Enter.
4. Start chatting with the bot!
